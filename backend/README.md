# SKS Quest - Backend API

## Модуль геймификации для мобильного приложения СКС Онлайн

---

## 🏗️ Архитектура

```
backend/
├── app/
│   ├── main.py          # Точка входа. FastAPI приложение + CORS + Swagger
│   ├── database.py      # Настройка SQLAlchemy (подключение к БД)
│   ├── models.py        # SQLAlchemy модели (таблицы БД)
│   ├── schemas.py       # Pydantic схемы (валидация данных)
│   ├── auth.py          # JWT авторизация + ролевая модель
│   ├── seed.py          # Тестовые данные для демонстрации
│   ├── routers/
│   │   ├── auth.py         # /api/auth/* - регистрация, вход
│   │   ├── daily.py        # /api/daily/* - ежедневный вход (streak)
│   │   ├── quests.py       # /api/quests/* - квесты
│   │   ├── wheel.py        # /api/wheel/* - колесо фортуны
│   │   ├── marketplace.py  # /api/marketplace/* - каталог призов
│   │   ├── leaderboard.py  # /api/* - лидерборд, лиги, достижения
│   │   └── analytics.py    # /api/analytics/* - дашборд аналитики
│   └── services/        # Бизнес-логика (для расширения)
├── requirements.txt     # Python зависимости
├── Dockerfile           # Docker образ
├── docker-compose.yml   # Docker Compose (PostgreSQL + Redis + API)
└── .env.example         # Пример переменных окружения
```

---

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск (SQLite)

```bash
# 1. Установи зависимости
pip install -r requirements.txt

# 2. Заполни БД тестовыми данными
python app/seed.py

# 3. Запусти сервер
uvicorn app.main:app --reload --port 8000

# 4. Открой Swagger документацию
http://localhost:8000/docs
```

### Вариант 2: Docker (PostgreSQL + Redis)

```bash
# 1. Собери и запусти контейнеры
docker-compose up --build

# 2. Заполни БД тестовыми данными
docker-compose exec api python app/seed.py

# 3. Открой Swagger
http://localhost:8000/docs
```

## 🎮 Игровые механики

### Ежедневный вход (Daily Check-in)
- 5 бонусов за каждый день
- 7 дней = +50 бонусов
- 14 дней = +150 бонусов
- 30 дней = +500 бонусов + бейдж "Постоянный гость"
- Серия сбрасывается при пропуске

### Колесо фортуны
- 1 бесплатная прокрутка в неделю
- Платная: 50 бонусов, максимум 5/день
- Прозрачные вероятности (требование комплаенса)

### Лиги
- Бронза → Серебро → Золото → Платина → Бриллиант
- Топ-10% переходят в высшую лигу ежемесячно
